About TrustLens AI

A production-ready review fraud analytics platform that combines text classification, explainability, network intelligence, and temporal anomaly detection.

What It Does

TrustLens AI analyzes current review content and uploaded datasets to surface suspicious review behavior. It combines TF-IDF text features, XGBoost classification, SHAP/LIME explainability, AI generation indicators, and dataset-driven fraud analytics.

Core Capabilities
  • Single Review Prediction: Real-time fraud scoring for any pasted review text.
  • Product URL Analysis: Attempts review retrieval from supported public product pages.
  • Batch CSV Upload: Loads datasets, persists analytics, and recalculates visualizations.
  • Explainability: SHAP and LIME outputs explain model decisions for each review.
  • Behavioral Intelligence: Reviewer risk scoring and network community detection from the current dataset.
  • Temporal Detection: Burst and velocity anomaly detection using time-series patterns.

Current Architecture

TrustLens AI is designed as a restart-safe Flask application with persisted dataset and analytics state.

Backend Flask blueprints, persistent JSON summary store, active dataset CSV persistence.
ML TF-IDF vectorization + XGBoost classifier with production inference validation.
XAI SHAP feature importance and LIME word-level explainability per review.
Analytics Network, reviewer risk, temporal burst, and AI detection metrics generated from current input data.
Dataset Handling

The app persists active dataset rows to CSV and uses them for dashboard and investigation analytics. Uploaded data and current predictions update charts and risk calculations immediately.
